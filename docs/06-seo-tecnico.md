# 06 - SEO Técnico

> Documento que reúne as diretrizes técnicas de SEO para o site da Akai Móveis.

# Objetivo

Garantir que o site ofereça uma excelente experiência para usuários e mecanismos de busca, facilitando a indexação e aumentando o potencial de ranqueamento.

---

# Estrutura HTML

Cada página deve possuir:

- Apenas um H1.
- Hierarquia lógica de H2 e H3.
- Títulos descritivos.
- HTML semântico sempre que possível.

---

# URLs

As URLs devem ser:

- Curtas.
- Descritivas.
- Sem parâmetros desnecessários.
- Escritas com hífens.

Exemplo:

/cozinhas-planejadas

---

# Meta Tags

Todas as páginas importantes devem possuir:

- Title exclusivo.
- Meta description personalizada.
- Open Graph.
- Twitter Cards quando aplicável.

---

# Robots.txt

Manter um arquivo robots.txt válido.

Permitir a indexação das páginas públicas e bloquear apenas áreas administrativas ou irrelevantes para busca.

---

# Sitemap XML

O sitemap deve ser atualizado sempre que novas páginas forem publicadas.

Após alterações importantes, enviar novamente ao Google Search Console.

---

# Dados Estruturados

Utilizar Schema.org quando aplicável.

Prioridade para:

- Organization
- LocalBusiness
- WebSite
- BreadcrumbList
- Product
- FAQ
- ImageObject

Os dados estruturados ajudam os mecanismos a compreender melhor o conteúdo.

---

# Imagens

Todas as imagens devem:

- possuir texto alternativo (ALT);
- utilizar nomes de arquivo descritivos;
- ser comprimidas;
- manter boa qualidade visual.

Sempre priorizar fotos reais dos projetos da Akai.

---

# Links Internos

Criar ligações entre páginas relacionadas.

Exemplos:

Homepage → Cozinhas Planejadas

Cozinhas Planejadas → Cozinhas Moduladas

Blog → Serviços

Isso distribui autoridade dentro do site.

---

# Performance

Monitorar continuamente:

- Core Web Vitals;
- velocidade de carregamento;
- tamanho das imagens;
- scripts desnecessários.

A experiência do usuário deve ser prioridade.

---

# Indexação

Após publicar páginas importantes:

- verificar indexação;
- acompanhar Google Search Console;
- corrigir erros rapidamente.

---

# Canonical

Sempre utilizar URLs canônicas quando houver risco de conteúdo semelhante.

---

# Breadcrumbs

Implementar breadcrumbs nas páginas internas para facilitar navegação e compreensão da estrutura do site.

---

# Checklist

- HTML semântico.
- Robots.txt atualizado.
- Sitemap XML válido.
- Schema.org implementado.
- ALT em todas as imagens.
- Links internos consistentes.
- Core Web Vitals monitorados.
- Search Console revisado regularmente.
